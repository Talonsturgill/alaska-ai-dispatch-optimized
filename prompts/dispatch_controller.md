# Alaska AI Dispatch daily controller

Operate only this canary checkout. The controller state, compact story packet,
cached standing context, exact artifacts, and existing correctness gates are the
complete working set. Do not inject the repository, archived runs, the legacy
master prompt, or broad craft folders into a model call.

The daily contract is America/Anchorage, 112–130 seconds, and 262–282 spoken
words. Produce a 1080×1920 master, measured 1080×1080 square, and 720×1280
mobile rendition. A 1080×1350 or other 4:5 deliverable is forbidden.

Use the Carousel fact pack for the run date when all four files exist:
`selection.md`, `claims.json`, `scout_merge.md`, and `run_state.json`. The packet
builder extracts a bounded, hash-traceable subset. Normal daily research uses
zero broad searches. Only a missing fact pack permits the bounded fallback,
which allows at most ten broad searches and five candidates. Never invent a
claim, source, quote, date, number, or Alaska impact.

Follow the machine state exactly:

`planning → packet_context → fact_validation → angle →
vo_storyboard_episode_props → gates → render_preflight → judges_round_1`.

Three independent judges evaluate the exact evidence. A pass reaches `SHIP`. A
failure permits one repair, then three final independent judges. A second
failure reaches `BLOCKED_QUALITY`; do not lower a gate, add a second repair, or
publish below the bar.

Reserve every model call before making it and record provider usage afterward.
Use one high-tier showrunner; mid-tier production, validation, and judges; and
the optional cheap triage call only when its phase allows it. Reuse the static
context cache key. Do not repeat the standing prompt or load broad repository
context into later calls. Stop before the next call if any call, token, search,
or cost budget would be exceeded.

During a daily run, do not edit prompts, agents, scripts, config, shared visual
libraries, `DispatchDaily.tsx`, or `Root.tsx`. Maintenance is a separate weekly,
human-reviewed branch. The canary may only create local run artifacts and the
existing canary-safe outputs. Production feeds, foreign repositories, email,
social posting, schedules, secrets, and external uploads remain unavailable.
